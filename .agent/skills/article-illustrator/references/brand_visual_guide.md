# 数据小虾米 - 配图品牌视觉指南

## 品牌色板

```
Primary (核心/重点):    #FF6B35  Orange     用于标注核心概念、高亮关键元素
Secondary (结构/框架):  #004E89  Navy Blue  结构线、边框、次要元素、流程连接线
Background:            #FDF6EC  Cream      浅米色/米白，白板/笔记本感
Muted (弱化/反面):      #B0B0B0  Light Gray 对比中的反面部分、已完成状态
Success (正面):         #2ECC71  Green      仅用于检查清单的勾选标记
```

## 视觉风格定义

### 核心风格：白板手绘 + 信息图

| 属性 | 规范 |
|------|------|
| 线条 | 手绘感，略有不规则，非完美几何线 |
| 标注 | 中文优先，带箭头/虚线指向标注对象 |
| 背景 | 浅米色/奶白色，模拟白板或笔记本纸张 |
| 图标 | 简约线条图标，非实心填充 |
| 文字 | 手写风格字体感，但保持可读性 |

### 必须避免

| 属性 | 禁止项 |
|------|--------|
| 背景 | 深色/黑色科技感背景 |
| 渲染 | 3D 写实渲染、光效、反射 |
| 风格 | 素材网通用矢量图 |
| 元素 | 人物照片、产品截图 |
| 文字 | 纯英文标注（目标读者为中文用户） |

## 水印规范

- **位置**：右下角
- **内容**：小虾米（shrimp）简约剪影图标
- **大小**：占图片面积 < 3%
- **透明度**：保持可见但不影响主体内容

## Prompt 尾部标准片段

所有配图 prompt 末尾必须附加：

```
Small cute shrimp silhouette icon as watermark in bottom-right corner.
Style: clean whiteboard/notebook sketch on light cream/off-white background. 
Hand-drawn lines, circles, arrows, and dotted annotations. 
Orange (#FF6B35) highlights on key concepts, navy blue (#004E89) for structural elements. 
NO photorealism, NO 3D rendering, NO dark background. 
16:9 landscape format.
```

## 图片规格

| 属性 | 规范 |
|------|------|
| 比例 (内文) | 16:9（横向图） |
| 比例 (封面) | 2.35:1（微信公众号首图标准） |
| 用途 | 公众号/知乎文章头图与内嵌图 |
| 格式 | PNG |
| 命名 | kebab-case，描述内容而非编号 |
