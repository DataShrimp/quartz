# RedBook (小红书) Algorithm & Content Strategy (2025)

## 1. 算法核心机制 (2025)

*   **CES Scoring**: 关注 (最高) > 评论 (次高) > 转发 (高) > 收藏 (中) > 点赞 (基础)
*   **Golden 2 Hours**: 发布后 2 小时内的互动决定内容生死。
*   **Search Weight**: 搜索流量占比接近 50%，标题前 10 字权重超 60%。
*   **Originality**: 原创性权重 35%+。
*   **Info Density**: 图文需包含 3+ 有效信息点。

## 2. 内容策略

### 2.1 内容类型定位
*   **硬核知识** → 第二大脑展示 / 概念可视化
*   **项目复盘** → 3 分钟看懂 / 踩坑分享
*   **生活切片** → 真实记录 / 情绪共鸣
*   **工具教程** → 手把手教程 / 效率提升

### 2.2 标题设计 (Hook)
*   **规则**: 前 10 字必须含核心关键词。
*   **元素**: 利益点 / 悬念感 / 数字 / 情绪价值。
*   **公式**:
    1.  数字 + 痛点：「7 个 AI 工具让我效率翻倍」
    2.  悬念型：「用了 3 年才发现，原来 xxx 可以这样」
    3.  共鸣型：「如果你也在焦虑 xxx，这篇给你」
    4.  对比型：「普通人 vs 高手的 xxx 区别」
    5.  避坑型：「千万别这样 xxx，我踩过的坑」

### 2.3 正文结构
1.  **开头 (Hook)**: 场景代入 / 痛点共鸣 / 反常识观点。
2.  **核心内容**: 分点呈现，每点配 Emoji 作为视觉锚点。
3.  **结尾 (CTA)**: 引导评论、收藏、关注。
4.  **排版**: 
    *   "个人分享"口吻，亲切自然。
    *   段落简短，多用 bullet points。
    *   每 50 字左右换行。
    *   Emoji: ✨💖📅✅⚠️🔥💡

### 2.4 互动设计
*   埋入互动钩子：「你们有没有遇到过...？」、「收藏 = 学会了」。

## 3. 配图规范
*   **封面**: 3:4 竖版，标题文字叠加，手绘感/活力色彩，3秒抓眼球。
*   **内容图**: 金句卡片 (1:1 方形)、流程图/概念图。
*   **风格**: 统一使用 "Data Shrimp" 品牌色调。

## 4. Tags Strategy
*   5 个大流量通用标签 + 3 个垂直精准标签 + 2 个长尾蓝海词。
*   固定标签: #数据小虾米 #AI学习
