# Twitter (X) Algorithm & Thread Strategy (2025) - Bilingual (CN/EN) Required

## 1. Algorithm Metrics
*   **Engagement**: Likes (+30), Retweets (+20), Replies (+1).
*   **Timing**: First 30 mins are critical. Reply within 2 hours.
*   **Priority**: Rich Media > Threads > Conversations.
*   **Anti-Patterns**: 
    *   No external links in First Tweet (Severe penalty).
    *   Hashtag stuffing (Spam).
    *   Duplicate content.

## 2. Content Strategy (Growth Hacker)

### 2.1 The Hook (First Tweet)
*   **Rule**: NO EXTERNAL LINKS.
*   **Styles**:
    *   **Result**: "How I achieved [Result] in [Time]..."
    *   **Warning**: "90% fail at [Topic] because..."
    *   **Curator**: "I read 5000 words on [Topic], here are 7 key takeaways:"

### 2.2 Thread Structure (5-10 Tweets)
1.  **T1 (Hook)**: Attention grabber.
2.  **T2-3**: Context/Pain point.
3.  **T4-7**: Core insights (One point per tweet).
4.  **T(N-1)**: TL;DR Summary.
5.  **T(N) CTA**: Hard sell (Link) + Soft sell (Follow).

### 2.3 Formatting
*   Short sentences.
*   Visual anchors (Emoji: 👇 ✅ 🧵 💡 🔥).
*   No "Translationese" (avoid "In conclusion", "Therefore").
*   **Independent Value**: Reader gets 80% value without clicking the link.

## 3. CTA Strategy
*   **Soft Sell**: "Follow @[Handle] for more on [Topic]."
*   **Hard Sell**: Link in the **last** or **second to last** tweet.

## 4. Bilingual Output (Mandatory)
*   Output TWO complete threads: One in English, One in Simplified Chinese.
*   Do not mix languages in a single thread unless for specific terminology.

## 4. Visuals
*   **Cover**: 16:9, Modern Tech style.
*   **Inserts**: Comparison charts, Process diagrams.
