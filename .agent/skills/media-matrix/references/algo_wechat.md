# WeChat Official Account Strategy (2025)

## 1. Algorithm & Ecosystem
*   **Social Chain**: "Friends watching" (在看/朋友在看) has high weight.
*   **Metrics**: CTR, Completion Rate (>=50%), Share Rate (>=8%).
*   **Originality**: Required >= 30% to avoid throttling.
*   **Anti-Patterns**: Clickbait titles, Text-only (missed Video Channel traffic).

## 2. Content Strategy (Deep Dive)

### 2.1 Dimensionality Reduction (降维)
*   **Metaphors**: Explain tech with daily life concepts.
*   **Storytelling**: "Hero's Journey" narrative.
*   **Problem-Driven**: Start from pain points.

### 2.2 Structure (Retention Focused)
1.  **Hook (Header)**: Scenario/Pain point/Anti-common sense. "Have you noticed..."
2.  **Context**: Why it matters? Connection to reader.
3.  **Core**: One core point per section. "Breathing points" every 300 words (Image/Bold/Quote).
4.  **Takeaway**: Actionable advice.
5.  **CTA**: Like/Wow/Share.

### 2.3 Title Strategy
*   Formula: Number + Pain Point + Solution.
*   Styles: Suspense, Data, Pain Point, Anti-Common Sense, Companionship.

## 3. Formatting Rules
*   Perspective: First person ("I").
*   Tone: Sincere, "Logbook" style (航海日志). No preaching.
*   Visuals: 
    *   Cover: 2.35:1.
    *   Inline: Every 500 words (Concept/Flow/Quote).
    *   Video: 30s summary at end (link to Video Channel).

## 4. Branding Elements
*   **Footer**:
